# RVP — Random Voice Player

シナリオに沿って音声を再生するプログラマブルな音声プレイヤーです。
分岐・選択肢・変数・ランダム・BGM を組み合わせたシナリオを JSON で定義でき、
シナリオは付属の GUI エディタで作成できます。
対応デバイス(Intiface / TCode)や動画(mpv)との同期にも対応しています。

## 特徴

- **シナリオ駆動の再生**: イベントをつないだシナリオに沿って音声(wav/mp3)を再生。
  分岐・選択肢・数値入力・変数によって展開が変わります。
- **3チャンネル同時再生 + BGM**: L/C/R の3チャンネルで別々の音声を同時に鳴らせます。
  BGM チャンネルはイベントをまたいで曲を流し続けられます。
- **ランダムと重み**: 再生順・分岐先・待ち時間などを重みつきランダムにできます。
  重複なし抽選(袋方式)や、訪問済みイベントの除外にも対応しています。
- **ゲーム的なシナリオ**: 変数と分岐の組み合わせで、
　すごろく・クイズ・バトル(HP制)のようなシナリオが作れます。
- **GUI シナリオエディタ**: イベント遷移図を見ながらドラッグ&ドロップで
  音声を配置。変数の監視、再生しながらの動作確認もできます。
- **動画再生(任意)**: [mpv](https://mpv.io/) と連携して動画アイテムを再生できます。
- **デバイス連携(任意)**: [Intiface Central](https://intiface.com/central/) 経由の
  Bluetooth デバイス、および TCode 対応デバイス(シリアル接続)を、
  funscript / CSV スクリプトで音声と同期して動かせます。
  スクリプトの編集・パターン配置機能も内蔵。
- **背景イラスト**: 音声作品に同梱のイラストなどを再生画面全体の背景に
  表示できます(暗さ調整つき。表示のON/OFFは視聴側で切り替え可能)。
- **日本語 / English** の UI 切り替えに対応しています。

## 動作環境

- Windows 11 (64bit)
- (任意) 動画再生: mpv
- (任意) デバイス連携: Intiface Central、または TCode 対応デバイス

## インストール

### 方法1: exe 版(推奨)

1. [Releases](../../releases) から最新の `RVP_v○○○_win.zip` をダウンロードします。
2. zip を展開し、`RVP` フォルダ内の **`RVP.exe`** を実行します
   (フォルダごと1セットです。exe 単体を移動しないでください)。

> **注意**: PyInstaller 製の exe はウイルス対策ソフトに誤検知されることが
> あります(既知の一般的事象です)。ブロックされた場合は、zip の展開先を
> 除外設定に加えるか、方法2のソース実行をご利用ください。

### 方法2: Python で実行

Python 3.12 以降がインストールされていれば、ソースから実行できます。

```bat
py -m pip install -r requirements.txt
py rvp_launcher.py
```

`requirements.txt` のうち tkinterdnd2(ドラッグ&ドロップ)と
pyserial(TCode 直結)はオプショナルです。未導入でも該当機能以外は動作します。

## シナリオを視聴する

1. RVP を起動し、「シナリオ」タブでシナリオファイル(`.json`)を選びます。
   配布シナリオは、音声ファイルごとフォルダで配置してください。
2. 「再生」タブに切り替わったら ▶ で再生開始。選択肢が出たらボタンで選びます。

デバイスを使う場合は、先に「接続」タブで Intiface Central への接続
(または TCode のポート選択)を行ってから再生してください。

## シナリオを作る

1. 「シナリオ」タブの「新規作成」(または既存シナリオの「編集」)で
   シナリオ編集画面を開きます。
2. イベントを選択し、チャンネル(L/C/R)へ「＋音声」
　　またはドラッグ＆ドロップで音声ファイルを配置します。
3. イベント同士を「次のイベント」でつなぎ、保存して「再生」タブで試します。

シナリオファイル(JSON)の完全なリファレンスは
[SCENARIO_FORMAT.md](SCENARIO_FORMAT.md) にあります。

## 動画を使う(任意)

動画アイテムの再生には mpv(無料)が必要です。mpv をインストールし、
「接続」タブで mpv のパスを設定すると、シナリオ内の動画アイテムが
再生できるようになります。mpv がなくても動画以外の機能は全て使えます。

## 注意事項

- デバイスを使用する際は、機器の取扱説明書に従い、
　無理のない設定(可動範囲・強度)でご利用ください。
- シナリオファイルを配布する場合、
　ファイル内に絶対参照パスが含まれないことを確認してください。
　（絶対パス内の場合、PCのユーザー名が含まれてしまいます。）
