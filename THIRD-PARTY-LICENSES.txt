RVP (Random Voice Player) - Third-Party Licenses
================================================

RVP is licensed under the MIT License (see the LICENSE file).

This file lists the third-party software that RVP uses or that is
redistributed as part of the RVP binary distribution, together with the
full text of each license.

Sections 9-23 cover libraries that are bundled inside the pygame-ce
wheel for Windows (as DLLs) and are therefore redistributed together
with RVP: SDL2, SDL2_image, SDL2_mixer, SDL2_ttf, FreeType, libpng,
libjpeg, libtiff, libwebp, libogg, Opus, opusfile, WavPack, libxmp and
PortMidi.

Pillow (section 24) is a required dependency of CustomTkinter and is
also used directly by RVP for the background-image feature. The Pillow
binary wheel for Windows bundles additional codec libraries (zlib,
libjpeg-turbo, libtiff, libwebp and others); their notices are included
in the LICENSE file that ships inside the Pillow distribution
(pillow-*.dist-info/licenses/LICENSE), which is redistributed unchanged
inside the RVP binary distribution.

mpv is NOT bundled with RVP. If you use video playback, install mpv
yourself; its license terms are available at https://mpv.io/.

The BIZ UD Gothic font (SIL Open Font License 1.1) is NOT bundled; RVP
uses the copy that ships with Windows 10 (1809) and later.

Mathematisch Centrum (CWI, see https://www.cwi.nl) in the Netherlands
